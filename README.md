#  Indian Legal Advisor Chatbot (Powered by Groq)

An AI-powered legal chatbot that provides **Indian law–focused guidance** using ultra-fast inference from **Groq LPU™ infrastructure**.  
The bot strictly answers legal queries and rejects non-legal questions.

> ⚠️ Disclaimer: This project is for educational purposes only and does not replace professional legal advice.

---

## 🚀 Features

- ✅ Legal-only chatbot (court, IPC, CrPC, Constitution, civil law, etc.)
- ✅ Ultra-fast responses using Groq API
- ✅ Automatic non-legal query rejection
- ✅ Structured legal explanations
- ✅ Simple terminal-based interface
- ✅ Google Colab & local compatible

---

## 🧠 Tech Stack

- Python 3.9+
- Groq API
- Model: `llama3-70b-8192`
- Environment: Google Colab / Local CPU
